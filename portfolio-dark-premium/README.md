# Portfolio Ethane Zimmermann — refonte Dark Premium

## Stack
- React + TypeScript
- Vite
- CSS moderne (sans framework CSS imposé)
- Lucide React pour les icônes

## Lancer le projet
Prérequis : Node.js récent (20+ recommandé).

```bash
npm install
npm run dev
```

Pour vérifier la compilation de production :
```bash
npm run build
npm run preview
```

## À personnaliser avant publication
1. Dans `src/App.tsx`, remplacer `contact@exemple.fr` par la vraie adresse e-mail.
2. Vérifier les liens GitHub, CV, rapports et documents.
3. Vérifier les intitulés, descriptions et technologies de chaque projet.
4. Actualiser le CV PDF si nécessaire.
5. Tester tous les liens et l'affichage sur mobile.

## Ressources
Les images, rapports PDF, certificats et le mini-site Sport Extrême proviennent de l'archive du portfolio initial. Les fichiers d'infrastructure CodeIgniter/PHP n'ont pas été copiés : cette nouvelle interface est une application front-end React indépendante.
